# Field-recorded interception audio

Author: Invadium. Source: https://freesound.org/people/Invadium/sounds/824805/
Title: cruise-missiles-interception-and-fly-by. Published 2025-09-02.
License: CC0 1.0 https://creativecommons.org/publicdomain/zero/1.0/
The author identifies the opening explosion as a cruise-missile interception recorded in Kyiv with a Zoom H4n Pro. Neither interceptor system nor microphone-to-interception distance is identified. This is not a measured near/far or PAC/Tamir-specific recording.
Downloaded public HQ preview: https://cdn.freesound.org/previews/824/824805_1011221-hq.mp3

Adaptation: retain 0.29–3.79 seconds, mono mix, remove DC/low rumble, filter high frequencies for distance, peak normalize and fade out. The near version retains the recording's reflections; it cannot reconstruct frequencies absent from the recording. Only three short Ogg derivatives are packaged. No music, dialogue, fly-by or air-raid siren segment is deliberately selected. No endorsement by the recorder is implied.
